Stacks (Q1–Q8)
Q1
Define the Stack ADT. What principle does it follow?
▼

A stack follows LIFO (Last In, First Out) — the most recently inserted element is removed first.

OperationTime

Precondition: pop() and top() require non-empty stack (underflow error otherwise).

Q5
How can you implement two stacks in a single array?
▼

Stack 1 grows from index 0 rightward. Stack 2 grows from index n-1 leftward. Overflow when they meet: top1 + 1 == top2.

init: top1 = -1, top2 = n
push1(x): top1++; A[top1] = x
push2(x): top2--; A[top2] = x
pop1(): return A[top1--]
pop2(): return A[top2++]

Total capacity shared — if one stack uses less, the other can use more.

Q7
How is the function call stack used during recursion? Trace factorial(3).
▼
factorial(3) pushed → calls factorial(2)
factorial(2) pushed → calls factorial(1)
factorial(1) pushed → base case, returns 1
factorial(2) pops → 2 × 1 = 2, returns 2
factorial(3) pops → 3 × 2 = 6, returns 6

Each call pushes a stack frame (local vars + return address). Stack overflow occurs when recursion is too deep.

Q10
Why is a circular array better than a linear array for queues?
▼

Linear: After dequeues, front moves right, leaving wasted empty slots. Reusing them requires O(n) shifting.

Circular: Uses mod arithmetic to wrap around: rear = (rear+1) % capacity. No wasted space, no shifting, all O(1).

Q12
What is a Deque? When would you use it?
▼

Deque (Double-Ended Queue) — insert/remove at both ends in O(1).

Use cases: Sliding window maximum, 0-1 BFS, palindrome check. Can act as both stack and queue.

Q13
Implement a stack using two queues.
▼
push(x):
    enqueue x onto Q2
    while Q1 not empty:
        dequeue from Q1, enqueue onto Q2
    swap Q1 and Q2

pop():
    return dequeue from Q1

push = O(n), pop = O(1). After push, Q1 has elements in stack order.

Q18
Prove MULTIPOP stack has O(1) amortised cost (Aggregate Method).
▼
Naive: MULTIPOP costs O(n) → n ops = O(n²)? Too pessimistic!
Proof: Each element pushed at most once (cost ≤ n). Each popped at most once (cost ≤ n). Total ≤ 2n. Amortised = 2n/n = O(1).

Key insight: You can't pop more than you've pushed.

Q19
Prove two-stack queue has O(1) amortised cost.
▼

Each element: push S1 (1) + pop S1 (1) + push S2 (1) + pop S2 (1) = 4 moves max.

n operations, at most n elements → Total ≤ 4n → Amortised = O(1).

Q20
Prove dynamic array insertion has O(1) amortised cost.
▼

Doubling capacity. Copy costs: 1+2+4+...+n < 2n. Plus n normal inserts.

Total < 3n → Amortised = 3n/n = O(1).

Q21
Why doubling gives O(1) amortised but adding a constant gives O(n)?
▼
StrategyTotal copiesAmortised
Doubling (×2)1+2+4+...+n = O(n) (geometric)O(1)
Adding constant cc+2c+3c+... = O(n²/c) (arithmetic)O(n)

Geometric growth makes resize cost negligible. Arithmetic growth does not.

Q23
Prove binary counter increment has O(1) amortised cost.
▼

Bit i flips n/2i times over n increments.

Total = n + n/2 + n/4 + ... = n × (1 + 1/2 + 1/4 + ...) < 2n

Amortised = 2n/n = O(1).

Lists (Q24–Q30)
Q24
Key advantage of doubly linked list over singly linked list?
▼

O(1) deletion given a node pointer. In singly linked, deleting needs the predecessor (O(n) traversal). In doubly linked, node.prev is already available.

Critical for: LRU Cache (move accessed node to front in O(1)).

Q26
Detect a cycle using Floyd's algorithm. Why does it work?
▼
slow = fast = head
while fast ≠ NULL AND fast.next ≠ NULL:
    slow = slow.next       // 1 step
    fast = fast.next.next  // 2 steps
    if slow == fast: return True (cycle!)
return False

Why: In a cycle, fast gains 1 step per iteration. Since cycle has finite length, fast catches slow. O(n) time, O(1) space.

Find start: After meeting, reset slow to head. Move both 1 step at a time — they meet at cycle start.

Q27
Design an LRU Cache (Doubly Linked List + Hash Map).
▼

DLL: Most recent at head, least recent at tail. HashMap: key → node pointer.

get(key):
    if in map: moveToHead(node), return value
    else: return -1

put(key, val):
    if in map: update val, moveToHead
    else: addToHead, if over capacity → removeTail

All operations O(1). DLL enables O(1) removal; HashMap enables O(1) lookup.

Q29
Implement a stack using a singly linked list in C.
▼
struct Node { int data; struct Node* next; };
struct Stack { struct Node* head; };

void push(struct Stack* s, int x) {
    struct Node* n = malloc(sizeof(struct Node));
    n->data = x;
    n->next = s->head;
    s->head = n;
}
int pop(struct Stack* s) {
    if (!s->head) return -1; // underflow
    struct Node* t = s->head;
    int val = t->data;
    s->head = s->head->next;
    free(t);
    return val;
}

All O(1). No overflow.
